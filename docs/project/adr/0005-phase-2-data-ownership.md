# ADR 0005: Phase 2 ownership and assisted consent

Status: assisted-consent workflow APPROVED 2026-10-10; implementation defaults described in PHASE_2_SPEC.md.

The founder supplied Hire_Me_Phase_2_Codex_Prompt_Approved_Assisted_Consent.md. Its addendum supersedes the earlier read-only admin plan. Preserve independent modules and migration 0001. Admin owns migration 0002; customer owns family/profile/request writes; admin owns restricted staff review/decisions/withdrawal verification; worker has no recipient access.

Use explicit staff grants, recent MFA, immutable review events, a two-person approval rule, scoped unexpired consent and immediate precautionary withdrawal freeze. Independent verification is a human process represented by protected evidence and auditable reviews, not a family checkbox or legal certification. Inability to consent remains blocked pending a separately established lawful-authority policy.

Versioned authenticated encryption protects notes/contact/evidence; transactions serialize access changes. Consent/audit evidence has no invented retention TTL. Pilot notice wording, accessibility, retention, recording and lawful authority require qualified review. See ../PHASE_2_SPEC.md for the access matrix and development defaults.
